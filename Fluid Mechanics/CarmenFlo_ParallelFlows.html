Equations and numerical method

Continuity: QT = ΣQi. Parallel condition: every branch has the same total head loss.

For each branch, hL = [f(L/D) + ΣK]V²/(2g), with standard fitting K = fT(Le/D), V = 4Q/(πD²), Re = ρVD/μ, and ΔP = ρghL.

Laminar flow uses f = 64/Re. Turbulent flow uses Swamee-Jain. Equivalent-length fitting losses use the fully turbulent Darcy factor fT based on relative roughness. The transitional range is flagged and linearly blended for educational continuity.

In known-flow mode, nested bisection finds the common head loss that satisfies continuity. In pressure/head mode, each branch flow is independently inverted from the common available loss, then summed.
